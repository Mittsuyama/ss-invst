# 关键行情区间 · 驱动因素分类与检索关键词

> 用法：对每个关键区间，按「公司名/代码 + 区间年份」搜索该时段公开信息，判断主导驱动，
> 并给归因口径标「已确认 / 推测 / 证据不足」。

## 驱动类型速查

| 驱动类型 | 典型表现 | 检索关键词（配合公司名/代码 + 年份） |
| --- | --- | --- |
| 业绩驱动 | 财报超预期/不及预期、业绩预告、利润拐点 | 年报、半年报、季报、业绩预告、净利润、营收、扭亏、暴雷 |
| 政策驱动 | 行业政策、补贴、监管、牌照 | 政策、规划、补贴、监管、集采、牌照 |
| 行业景气 | 行业周期、供需、涨价/降价 | 涨价、提价、供需、景气、周期、订单 |
| 事件驱动 | 并购重组、定增、回购、减持、大单、诉讼 | 重组、并购、定增、回购、减持、中标、诉讼、质押 |
| 资金/情绪 | 概念炒作、龙虎榜、机构抱团、北向资金 | 概念、涨停、龙虎榜、机构、北向、游资 |
| 宏观/市场 | 大盘系统性涨跌、利率、汇率 | 大盘、牛市、熊市、加息、降息、汇率、流动性 |

## 复盘要点（每段）

1. **定位时间窗口**：区间起止日期前后 ±1 个月的重点事件。
2. **判断是否业绩驱动**：看区间起点附近是否有财报 / 业绩预告（report_date 或公告日落在窗口内）。
3. **交叉印证**：同一驱动至少两个来源，或「公告 + 股价反应」同向。
4. **归因口径**：
   - 已确认：有明确公告/财报，且时间吻合、股价同向反应；
   - 推测：有相关信息但因果链不完整；
   - 证据不足：检索无果或信息矛盾。

## 常见误区

- 只凭「同期发生」就断言因果（相关 ≠ 因果）；
- 把大盘系统性涨跌归因到个股自身事件；
- 用后视镜视角，把后来的信息套到当时的行情上。
