# 财务报告分析 · 十类异常信号检查清单

> 用法：按顺序逐类逐项排查。每项先算比率/取数，再在 PDF 文字中搜关键词，最后给出结论。
> 结论三选一：**异常**（有明确证据）/ **正常**（数据无异常）/ **证据不足**（数据缺失，注明缺什么）。
> 金额单位统一「亿元」，比率两位小数。

---

## 一、现金流分析

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 货币资金覆盖率 | (货币资金 + 应收票据中银行承兑) / 流动负债 | 越高短期偿付越安全 |
| 货币资金覆盖率 | (货币资金 + 银行承兑) / 有息负债 | 覆盖有息债务能力 |
| 现金流净额/净利润 | 经营活动现金流量净额 / 净利润 | <1 长期偏低 → 盈利含金量差 |

### 1. 货币资金是否与经营增速匹配
- 数据来源：资产负债表「货币资金」（含现金及现金等价物、其他货币资金）、利润表「营业收入/净利润」、附注「利息收入」。
- 识别方法：对比货币资金增速 vs 营收增速 vs 净利润增速。货币资金长期高增长而营收/利润低增长、且利息收入明显偏低 → 货币资金可能虚增（「存贷双高」）。
- 搜索关键词：货币资金、受限资金、银行存款、利息收入、现金及现金等价物。
- 红旗信号：货币资金大增但利息收入/货币资金比率远低于存款利率；大额受限资金未披露。

### 2. 货币资金的来源是否主要是经营活动（警惕股、债、固定资产、部门出售）
- 数据来源：现金流量表「经营活动/投资活动/筹资活动产生的现金流量净额」。
- 识别方法：若货币资金增加主要靠筹资（发股、发债、借款）或投资（处置子公司/固定资产/部门），而非经营活动 → 经营造血能力弱。
- 搜索关键词：处置子公司、处置固定资产、发行股份、发行债券、借款、增资、出售。
- 红旗信号：连续多年经营净现金流为负或远小于货币资金增量，靠卖资产/融资补窟窿。

### 3. 是否存在现金流净额为正时，应付账款异常增加
- 数据来源：现金流量表「经营净额」、资产负债表「应付账款/应付票据」及账龄附注。
- 识别方法：经营净现金流为正的同时应付账款异常大增（增速远超营收/采购），可能是拖欠供应商虚增现金流、或配合虚增存货/收入。
- 搜索关键词：应付账款、应付票据、账龄、供应商。
- 红旗信号：应付账款周转天数持续拉长、且与毛利率异常变动同步。

## 二、负债分析

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 流动比率 | 流动资产 / 流动负债 | 参考均值 2 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | 参考均值 1 |
| 利息保障倍数 | EBIT / 利息费用 | 覆盖利息能力 |
| 有息负债占比 | 有息负债 / 总负债 | 越高财务压力越大 |

### 4. 是否存在高息债
- 数据来源：附注「有息负债明细」（短期/长期借款、应付债券、融资租赁、信托借款）。
- 识别方法：对比各项借款利率与同期基准/同行水平；明显高息且规模大 → 融资渠道受限、资金链紧张。
- 搜索关键词：借款、债券、票面利率、融资租赁、利息费用、信托。
- 红旗信号：借款利率显著高于市场或同行；存在非银高息融资（信托/民间）。

### 5. 是否存在借短投长
- 数据来源：资产负债表「短期借款、一年内到期的非流动负债」vs「在建工程、长期股权投资、固定资产、无形资产」。
- 识别方法：短期负债规模大、长期资产投入持续大 → 期限错配，流动性风险（短债长投）。
- 搜索关键词：短期借款、一年内到期的非流动负债、在建工程、长期股权投资。
- 红旗信号：短期借款占比高且长期资产快速扩张，流动比率/速动比率持续走低。

## 三、应收账款

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 应收占比 | (应收账款 - 银行承兑) / 流动资产 | 占比越高越依赖赊销 |
| 应收账款回款率 | 营业收入 / (应收账款年初年末均值) | 越高回款越快 |
| 长期应收账款占比 | 长期应收账款 / 总应收 | 账龄老化信号 |

### 6. 应收增长是否与营业收入增长相匹配
- 数据来源：资产负债表「应收账款」、利润表「营业收入」及应收账龄附注。
- 识别方法：应收账款增速显著高于营收增速，或应收占营收比例持续上升 → 放宽信用政策或虚增收入。
- 搜索关键词：应收账款、账龄、信用政策、回款。
- 红旗信号：应收增速 > 营收增速且回款率下降。

### 7. 应收账款计提比率是否存在异常
- 数据来源：附注「坏账准备计提政策」及账龄明细。
- 识别方法：坏账计提比例明显低于同行/历史；账龄老化但计提比例未变 → 少提坏账虚增利润。
- 搜索关键词：坏账准备、计提比例、账龄、信用减值损失。
- 红旗信号：账龄 1 年以上占比上升但计提率未相应提高；计提率显著低于可比公司。

### 8. 是否存在利用折旧摊销冲抵应收账款
- 数据来源：会计政策（折旧/摊销方法、会计估计变更）、应收账款核销附注。
- 识别方法：通过变更折旧/摊销方法（少提费用）掩盖应收回收困难；或长期挂账不核销、以减值转回冲抵。
- 搜索关键词：折旧、摊销、会计估计变更、应收账款核销、转销。
- 红旗信号：折旧摊销政策变更与应收异常同期出现；应收长期挂账却无核销。

## 四、存货

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 存货变动 | 存货期末较期初变动率 | 突增需警惕 |
| 存货周转率 | 营业成本 / (存货年初年末均值) | 越低积压越重 |
| 毛利率 | (营收 - 营业成本) / 营收 | 与存货变动交叉看 |

### 9. 注意突然变更的存货计价方法
- 数据来源：附注「会计政策」（存货计价方法：先进先出/加权平均/个别计价）。
- 识别方法：存货计价方法突然变更且未充分说明理由 → 操纵毛利率/营业成本。
- 搜索关键词：存货计价、先进先出、加权平均、个别计价、会计政策变更。
- 红旗信号：计价方法变更与毛利率突变同期，且无正当理由。

### 10. 农林渔牧、软件、集成电路、生物科技存货造假
- 数据来源：资产负债表「存货」（含消耗性生物资产、在产品、开发成本）、产能/采购附注。
- 识别方法：此类行业存货难盘点核实（生物资产、软件资本化、晶圆、在研），易虚增；交叉核对存货与产能、水电煤、采购、物流数据。
- 搜索关键词：消耗性生物资产、生物资产、在产品、开发成本、资本化。
- 红旗信号：存货高企但产能/能耗/采购不匹配；生物资产数量异常。

### 11. 是否是房地产公司（购地成本是存货而不是无形资产）
- 数据来源：资产负债表「存货-开发成本/开发产品」、附注行业分部。
- 识别方法：房企购地成本计入「存货（开发成本）」而非无形资产/固定资产，需按房企口径判断周转与减值。
- 搜索关键词：开发成本、开发产品、土地使用权、土地储备。
- 红旗信号：土地/开发成本长期挂账不计提减值；周转率显著低于行业。

## 五、固定资产，折旧和摊销

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 固定资产净额 | 资产负债表「固定资产」净额 | 跟踪变化 |
| 固定资产周转率 | 营业收入 / 固定资产净额 | 越低资产利用越差 |

### 12. 折旧政策是否有变更
- 数据来源：附注「会计估计变更」（折旧方法、折旧年限、残值率）。
- 识别方法：折旧方法/年限/残值率变更 → 少提折旧增利润或平滑利润；变更未充分披露更可疑。
- 搜索关键词：折旧方法、折旧年限、残值率、会计估计变更。
- 红旗信号：延长折旧年限/降低残值率与利润改善同期发生。

### 13. 是否存在在建工程延期转固定资产
- 数据来源：资产负债表「在建工程」、附注「重大在建工程」（预算、进度、完工情况）。
- 识别方法：在建工程长期挂账不转固 → 推迟开始计提折旧、虚增利润；对比工程进度与实际投产。
- 搜索关键词：在建工程、转固、达到预定可使用状态、竣工、试生产。
- 红旗信号：项目完工/投产多年仍挂账；进度 90%+ 却长期不转固。

### 14. 是否存在低估实物资产
- 数据来源：固定资产、存货、在建工程账面值与产能规模、重置成本对比。
- 识别方法：实物资产账面明显低于产能/重置成本 → 隐藏资产或人为低估以少提折旧。
- 搜索关键词：固定资产、产能、折旧、重置。
- 红旗信号：单位产能对应的固定资产远低于同行。

### 15. 是否存在在建工程后期追加过多资金
- 数据来源：附注「在建工程」预算、累计投入、进度。
- 识别方法：在建工程预算大幅超支、进度缓慢却持续追加投入 → 可能虚构在建工程套取/转移资金。
- 搜索关键词：在建工程、预算、进度、追加、累计投入。
- 红旗信号：累计投入远超预算且进度停滞。

### 16. 是否存在在建工程刚建成即维护
- 数据来源：附注「在建工程转固」与「修理费/更新改造支出」。
- 识别方法：项目刚转固即发生大额维修/更新改造 → 前期工程质量存疑，或借「费用化」腾挪利润。
- 搜索关键词：更新改造、修理费、维修、大修、技改。
- 红旗信号：转固当年即大额修理/技改支出。

## 六、投资

### 17. 是否存在大额减值冲销利润
- 数据来源：利润表「资产减值损失/信用减值损失」、附注（商誉、长期资产减值）。
- 识别方法：一次性大额资产/商誉减值 → 「洗大澡」，为来年扭亏做铺垫。
- 搜索关键词：减值、商誉减值、资产减值损失、计提减值。
- 红旗信号：单年大额减值后次年利润大幅反转。

### 18. 是否存在大额减值转回，增加利润
- 数据来源：利润表「资产减值损失」及附注（坏账/存货减值转回）。
- 识别方法：已计提减值转回直接增利，警惕靠非经常性损益包装利润。
- 搜索关键词：减值转回、坏账准备转回、转销、存货跌价转回。
- 红旗信号：减值转回占净利润比例高，且与主业经营无关。

### 19. 是否存在「持有到期资产」转「可供出售金融资产」
- 数据来源：附注「金融资产」（持有至到期投资、可供出售金融资产及重分类说明）。
- 识别方法：金融资产重分类（持有至到期 → 可供出售）改变计量基础，可隐藏浮亏或调节利润。
- 搜索关键词：持有至到期、可供出售金融资产、重分类、金融资产。
- 红旗信号：重分类发生当期利润/其他综合收益异常变动。

### 20. 房地产记录方式：投资模式？成本模式？
- 数据来源：附注「投资性房地产」后续计量模式。
- 识别方法：公允价值模式可增值且不提折旧、不拖累利润；成本模式计提折旧。关注模式切换对利润的影响。
- 搜索关键词：投资性房地产、公允价值模式、成本模式、后续计量。
- 红旗信号：为增利突然由成本模式改为公允价值模式，且缺乏充分依据。

### 21. 可供出售金融资产期末账面价值与成本的差额
- 数据来源：附注「可供出售金融资产」（账面价值、成本、公允价值变动）。
- 识别方法：AFS 按公允价值计量，差额计入其他综合收益，出售时转入利润 → 关注浮盈浮亏的利润调节空间。
- 搜索关键词：可供出售金融资产、公允价值、其他综合收益、账面价值、成本。
- 红旗信号：AFS 账面价值与成本差额巨大且集中在个别标的；出售时点「恰好」增厚利润。

### 22. 是否存在多元化投资
- 数据来源：资产负债表「长期股权投资、交易性金融资产、其他权益工具」及附注。
- 识别方法：大额跨界投资/理财/参股与主业无关 → 资金运用与主业匹配度低、减值风险高。
- 搜索关键词：长期股权投资、交易性金融资产、其他权益工具、理财、参股。
- 红旗信号：与主业无关的投资占比高、回报低或持续减值。

## 七、净资产

### 23. 是否存在大额未分配利润划入应付股利，从而增加 ROE
- 数据来源：资产负债表「未分配利润、应付股利」、利润表「净利润」、权益变动表。
- 识别方法：大额分红把未分配利润转为应付股利 → 净资产（分母）变小，ROE 虚高。
- 搜索关键词：应付股利、未分配利润、分红、利润分配。
- 红旗信号：宣布大额分红后 ROE 明显抬升，但经营实质未改善。

### 24. 是否存在先大额分红，随即大额融资
- 数据来源：现金流量表「分配股利支付的现金」「吸收投资/借款收到的现金」、分红附注。
- 识别方法：大额分红后立即定增/发债/借款 → 疑似利益输送或资金链异常。
- 搜索关键词：分红、股利、定增、发行股份、借款、再融资。
- 红旗信号：分红与再融资时间贴近、金额相当。

## 八、营业收入

### 25. 是否存在确认原则变更（财报搜索「满足以下条件时确认」）
- 数据来源：附注「收入确认会计政策」。
- 识别方法：收入确认时点/条件变更 → 提前或延后确认收入；对比新旧准则描述及对当期收入影响。
- 搜索关键词：收入确认、满足以下条件时确认、履约义务、控制权转移、时点法、时段法。
- 红旗信号：确认时点前移/条件放宽与收入增长同期发生；未披露变更影响金额。

## 九、费用

**先算的比率**（近 3 年）：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| 费用率 | (销售费用 + 管理费用 + 正财务费用) / 毛利 | 突变需警惕 |
| 员工平均年薪 | (Δ应付职工薪酬 + 支付给职工的现金) / 员工总数 | 与同行比对 |

### 26. 销售、管理费用是否和营业收入增加匹配
- 数据来源：利润表「销售费用、管理费用」、营业收入。
- 识别方法：费用增速显著低于营收增速（费用刚性异常下降）或费用率突变 → 费用资本化/隐藏费用。
- 搜索关键词：销售费用、管理费用、费用率、职工薪酬。
- 红旗信号：营收大增但费用几乎不增、或费用率异常下滑。

### 27. 是否存在费用划入长期待摊费用（转资产）
- 数据来源：资产负债表「长期待摊费用」及附注明细。
- 识别方法：长期待摊费用异常增加（大额费用资本化）→ 延迟确认费用、虚增当期利润。
- 搜索关键词：长期待摊费用、资本化、摊销、装修费、开办费。
- 红旗信号：长期待摊费用激增且构成含糊（广告/装修等本应费用化）。

### 28. 是否存在人为制造扭亏为盈行为（微亏改大亏）
- 数据来源：利润表「净利润」、减值/费用/预计负债附注。
- 识别方法：本可微利/微亏却刻意做大亏损（大额计提、费用前置）→ 为次年扭亏留空间；关注「洗大澡」+ 次年反转。
- 搜索关键词：减值、预计负债、计提、扭亏、亏损。
- 红旗信号：某年巨亏后次年「扭亏为盈」，且扭亏主要靠减值转回/非经常性损益。

## 十、其他

### 29. 关联业务：是否存在非同一控制下的股权交易作价显失公平
- 数据来源：附注「关联方及关联交易」、重大资产重组/股权收购公告、评估报告。
- 识别方法：关联方/非同一控制下股权交易定价偏离公允价值 → 利益输送；关注评估方法、作价依据、增值率。
- 搜索关键词：关联交易、同一控制、非同一控制、评估、作价、股权转让、增值率。
- 红旗信号：交易作价显著高于/低于公允价值或可比交易，且关联方受益。

## 结论汇总与风险分级

排查完成后，把每项结论汇总为：

- **红色（高危）**：证据明确、金额重大的异常项；
- **黄色（关注）**：数据异常但证据不足、或金额较小；
- **绿色（正常）**：数据正常无异常。

最终报告按「红色 > 黄色 > 绿色」排序呈现，每项附一句依据。所有结论须注明「观察到的信号」而非「已证实的造假」，不作定性指控。
