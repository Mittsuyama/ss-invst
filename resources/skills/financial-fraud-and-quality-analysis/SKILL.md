# 财报造假排雷与经营质量分析

## 目标

获取近 3 年年报 PDF，对一家 A 股公司逐项排查十类、约 30 项财务异常/造假信号，产出一份「财务质量报告」（每项给出「异常 / 正常 / 证据不足」结论与依据）。

## 步骤

1. **确定标的**：用 search_stock 确定 `secid`；用 get_quote 获取行业、市值快照（用于判断是否为房企/农牧/软件/集成电路/生物科技等特殊行业）。
2. **获取近 3 年 PDF**：先确认 `uploads/` 是否已有年报 PDF；没有则用 download_url 从东方财富 / 巨潮资讯下载近 3 年年报 PDF（见下方「年报 PDF 来源」）。
3. **提取 PDF 文字**：用 read_file 逐份读取 PDF，抽取「审计意见、会计政策与会计估计变更、报表附注、管理层讨论与分析、关联交易、或有事项」，存入 `intermediate/`（如 `intermediate/{年份}-pdf-text.md`）。
4. **取数**：用 get_financial_statements 获取近 3 年三大报表与领先指标（毛利率/净利率/ROE/周转天数等）；缺口用 tushare_query（income/balancesheet/cashflow/fina_indicator）补充。
5. **逐项排查**：用 read_file 读 `references/checklist.md`，按十类、约 30 项逐条执行——对每项计算对应比率、在 PDF 文字中搜索关键词、给出结论与证据。
6. **生成报告**：按 `templates/report.md` 结构，用 save_file 保存到 `output/`（文件名如「公司名-财务质量报告-YYYY-MM-DD.md」）。

## 年报 PDF 来源

- 东方财富：`https://pdf.dfcfw.com/pdf/H2_{公告ID}_{n}.pdf`；或通过巨潮资讯网检索公告编号。
- 若自动下载失败，提示用户手动上传近 3 年年报 PDF 到会话 `uploads/`。
- 校验：read_file 读 PDF 返回的文字应包含「合并资产负债表」「合并利润表」等报表标题，否则判定下载/解析失败，换来源重试。

## 执行循环

- 开始前用 update_todo 列出步骤（定标的、取 PDF、提文字、取数、逐项排查、写报告）；
- 关键选择（目标股票、PDF 来源、结论口径）用 decide 记录理由；
- **每步校验**：PDF 文字为空/报表缺失 → 换下载源或请用户补充；get_financial_statements 返回空 → 用 tushare_query 补数；某项数据缺失 → 结论标「证据不足」并注明缺哪份数据，不编造；
- 失败时 read_todo 恢复进度后重试或换方案（refine）；
- 全部完成后 update_todo 标 done。

## 验收标准（报告须满足）

- 覆盖 checklist 全部十类约 30 项，每项都有「结论（异常/正常/证据不足）+ 依据（数字或财报原文关键词）+ 风险提示」；
- 比率表填满近 3 年实际年份数据，金额统一「亿元」，比率两位小数；
- 数据缺失标「--」并说明，不编造；引用财报文字注明所在章节。

## 注意

- 逐项下结论时用「数据 + 财报原文」交叉印证，避免仅凭单一指标断言；
- 区分「观察到的异常信号」与「已证实的造假」，不作定性指控；
- 末尾风险提示与免责声明：本报告不构成投资建议。
