# 因子研究与统计流程

## 目标

研究某个技术因子的有效性，例如「MACD 多次交叉买入后的胜率与赔率」。

## 步骤

1. 确定要研究的股票样本（用 search_stock 确定 secid，可多只）。
2. 用 analyze_factor 对每只股票做事件回测，得到胜率、赔率、平均盈亏与交易明细。
3. 尝试不同参数（如 ma_cross 的 short/long、rsi 的超买超卖阈值）对比结果。
4. 汇总多只股票、多组参数的结果，判断因子是否稳健。
5. 用 save_file 保存统计报告。

## 指标含义

- winRate：胜率（盈利交易数 / 总交易数）
- profitFactor：赔率（总盈利 / 总亏损；>1 表示整体盈利）
- avgWin / avgLoss：平均单笔盈利 / 亏损
- totalTrades：总交易次数

## 执行循环

- 开始前用 update_todo 列出步骤（定样本、回测、调参对比、汇总、保存）；
- 关键选择（样本范围、因子与参数）用 decide 记录理由；
- 每步执行后校验：回测样本不足/结果为空时，用 read_todo 恢复进度后扩大样本或换参数重试；
- 完成后 update_todo 标 done，用 save_file 保存统计报告。

## 注意

- 样本越多、周期越长，结论越可信；
- 历史回测不代表未来表现，明确提示过拟合风险；
- 报告中区分「观察到的统计」与「因果推断」。
